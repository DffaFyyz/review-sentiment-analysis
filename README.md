# Amazon Review Sentiment Analysis

This project trains and serves a multiclass sentiment classifier for Amazon food review text.

## Files

- `main.ipynb`: full notebook workflow for EDA, preprocessing, training, evaluation, and artifact export.
- `api.py`: Flask API for inference.
- `Reviews.csv`: source dataset.
- `sentiment_pipeline.pkl`: improved single-artifact pipeline generated by `main.ipynb`.
- `model_metadata.json`: metrics, threshold, label mapping, and training metadata generated by `main.ipynb`.
- `sentiment_model2.pkl` and `tfidf_vectorizer2.pkl`: legacy fallback artifacts if restored to the project root.

## Setup

Use Python 3.11 if possible because the notebook was created with Python 3.11.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

This local machine also has a conda environment named `classical_nlp` that can run the notebook.

## Train Improved Multiclass Model

Open and run:

```bash
jupyter notebook main.ipynb
```

Or execute it from the terminal:

```bash
conda run -n classical_nlp jupyter nbconvert --to notebook --execute --inplace main.ipynb
```

The notebook:

- performs graphical and non-graphical EDA at the beginning;
- removes exact duplicate review texts before splitting;
- keeps 3-star reviews as the neutral class;
- cleans review text;
- uses stratified train/validation/test splits;
- uses TF-IDF with stopword removal, `sublinear_tf`, `min_df`, `max_df`, and bigrams;
- compares Complement Naive Bayes, balanced Logistic Regression, and balanced SGD logistic models;
- selects the best model using validation macro F1 with neutral recall as a tie-breaker;
- evaluates with accuracy, balanced accuracy, macro F1, weighted F1, ROC-AUC, PR-AUC, classification report, and confusion matrix;
- adds a learning curve for macro F1;
- saves one scikit-learn pipeline artifact to `sentiment_pipeline.pkl`;
- saves metadata and metrics to `model_metadata.json`.

## Run API

```bash
python api.py
```

The API prefers `sentiment_pipeline.pkl` when it exists. If that file does not exist, it falls back to legacy `tfidf_vectorizer2.pkl` and `sentiment_model2.pkl` files if they are present in the project root.

Health check:

```bash
curl http://localhost:5000/health
```

Prediction:

```bash
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"text":"This product tastes great"}'
```

Example response:

```json
{
  "ulasan_asli": "This product tastes great",
  "label": 2,
  "sentimen": "Positif",
  "confidence_score": "94.25%"
}
```

## Run Frontend

The React frontend lives in `frontend/` and uses Vite, TypeScript, Tailwind CSS, React Router, Recharts, and Lucide icons.

```bash
cd frontend
npm install
npm run dev
```

By default, the frontend expects the Flask API at:

```text
http://localhost:5000
```

To override it, create `frontend/.env`:

```text
VITE_API_BASE_URL=http://localhost:5000
```

Frontend pages:

- `/`: sentiment prediction tool
- `/analysis`: EDA, preprocessing, feature extraction, model comparison, evaluation metrics, confusion matrix, and learning curve

## Notes

Run commands from the project root. The API and notebook expect the dataset and artifacts to be in this directory unless paths are changed in the notebook.
